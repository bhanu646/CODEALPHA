# 🤖 Basic Chatbot using Python

## 📌 Project Overview

This project is a simple **rule-based chatbot** developed using Python as part of the **CodeAlpha Python Programming Internship**.

The chatbot responds to predefined user inputs such as greetings and common questions. It demonstrates the use of fundamental Python concepts including functions, conditional statements, loops, and user input/output.

---

## 🎯 Objective

Build a basic chatbot that interacts with users through the command line using predefined responses.

---

## ✨ Features

* Greets the user.
* Responds to common questions.
* Uses predefined replies.
* Handles unknown inputs gracefully.
* Ends the conversation when the user types **"bye"**.

---

## 🛠 Technologies Used

* Python 3.x

---

## 📚 Python Concepts Used

* Functions
* `if-elif-else` statements
* `while` loop
* User Input (`input()`)
* Output (`print()`)
* String methods (`lower()`, `strip()`)

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this project.
3. Open the project folder in your terminal or command prompt.
4. Run the following command:

```bash
python chatbot.py
```
